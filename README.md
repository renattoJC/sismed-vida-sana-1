# SISMED Vida Sana

## Documentación técnica

Consulta la [documentación Javadoc](https://renattoJC.github.io/sismed-vida-sana-1/javadoc/).

La documentación se genera con Maven mediante:

```powershell
mvn javadoc:javadoc
```

El sitio publicado se actualiza automáticamente desde `docs/javadoc` al subir cambios a la rama `main`.
